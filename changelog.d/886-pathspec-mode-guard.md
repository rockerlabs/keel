- `tools/public-audit.sh`, `tools/self/doctor.sh`, `tools/self/citation-resolvability.sh`, `tools/self/prose-drift.sh`, `tools/drydock/inventory.sh` and the shared `tools/lib/repo-arg-guard.sh` now unset the four pathspec-mode variables (`GIT_LITERAL_PATHSPECS`, `GIT_GLOB_PATHSPECS`, `GIT_NOGLOB_PATHSPECS`, `GIT_ICASE_PATHSPECS`) on a second line next to the repo-selector guard, as `tools/doctor.sh` already did. An exported `GIT_LITERAL_PATHSPECS` or `GIT_NOGLOB_PATHSPECS` made the public audit read its `:(exclude)` pathspecs literally and raise a false private-token GAP on a path the config allows, and an exported `GIT_ICASE_PATHSPECS` made an allowed `vend/*` also swallow `Vend/` — a false clean; the drydock inventory's `*.md` scope silently came up empty (dir #886).
