- **dir #814: the branch-cleanup tool now grades a repo that has no remote.** `tools/branch-cleanup.sh` used to resolve the default branch as "origin/HEAD's target, else `main`", so a local-only repo whose default is `master` got `no main to compare against (fetch first?)` and nothing was graded. With no remote it now reads the local default (`init.defaultBranch`, then `main`, then `master`, whichever exists as a local branch; the checked-out branch is never the base), and a new `KEEL_DEFAULT_BRANCH` env var names the default outright. The `(fetch first?)` hint is kept only for a repo that has a remote, and the no-remote message names the override instead.
