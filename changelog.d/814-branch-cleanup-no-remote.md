- **dir #814: the branch-cleanup tool now grades a repo whose default branch is not `main` and has no fetched `origin/HEAD`.** `tools/branch-cleanup.sh` used to resolve the default branch as "origin/HEAD's target, else `main`", so a local-only repo whose default is `master` got `no main to compare against (fetch first?)` and nothing was graded. Without `origin/HEAD` (no remote, or one never fetched) it now reads the local default: the main worktree's branch when that is `main`, `master` or `init.defaultBranch`, then `init.defaultBranch`, `main`, `master`, whichever exists as a local branch; an arbitrary checked-out branch is never the base. A new `KEEL_DEFAULT_BRANCH` env var names the default outright. The `(fetch first?)` hint is kept only for a repo that has a remote, and the no-remote message names the override instead.
