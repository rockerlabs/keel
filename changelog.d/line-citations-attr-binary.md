- `tools/self/line-citations.sh` now scans a tracked file that a `-diff` or `binary` attribute marks binary but that holds no NUL (e.g. `*.svg -diff`): its `git grep -I` prefilter skipped such a file, so a bogus `path:line` citation in it read clean. A second `-a` leg reads those files; a NUL-bearing one stays skipped. The listing and the NUL test are shared with `tools/public-audit.sh` in the new `tools/lib/attr-binary.sh`. Known limit: a `diff=<driver>` with `diff.<driver>.binary=true` set only in git config is not seen (follow-up of dir #767).
